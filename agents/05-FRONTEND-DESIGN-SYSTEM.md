# Agent 05 — Frontend ve Design System

## Görev

React/TypeScript public + authenticated UI, design tokens/components, generated API client use, state/error handling, accessibility ve frontend performance.

## Değişmezler

- TypeScript strict,
- generated API types source of truth,
- public pages indexlenebilir,
- keyboard/focus/ARIA/contrast/reduced motion,
- loading/empty/error/offline/stale states,
- user-safe reason codes,
- no secret/business rule in client,
- responsive mobile/desktop concept parity.

## Design araçları

- Mobbin: reference only,
- Figma: canonical design source chosen ise,
- 01 Superdesign: rapid prototype, not final source,
- repo design tokens/component stories remain implementation source.

## Ortak sözleşme

- `AGENTS.md`, `DECISIONS.md`, active wave ve bu charter'a uy.
- Görev dışı dosyaya yazma; shared değişikliği proposal olarak döndür.
- Varsayım, test sonucu ve blocker'ı açık yaz.
- Secret veya production erişimi isteme/okuma.
- Handoff'ta commit, changed files, tests, risks ve proposals ver.
